# Happy Studios - Photography Website Demo

A premium photography website concept created as a demo for Happy Studios, Dindigul.

## Features

- Responsive mobile-first design
- Premium photography-focused layout
- Services section
- Portfolio/gallery
- Client review section
- Contact section
- Smooth scrolling
- Scroll animations
- Mobile navigation

## Technologies

- HTML5
- CSS3
- JavaScript

## Status

This is a demo/concept website.

Actual business information, photographs, contact details and social media links should be added only after approval from the business owner.
